# EFH · École Fly Hyani Privé — Marrakech cabin-crew spot

Vertical motion-graphics ad (1080×1920, 30 fps, 45 s) built on the Moroccan-Darija voiceover, with word-synced Arabic captions.

**Final video:** `out/EFH_Marrakech_CabinCrew_9x16.mp4`

## How it's made
- `index.html` + `main.js`, `scenes2.js`, `scenes3.js` — the whole animation as one GSAP timeline. Every frame is a pure function of time (`window.seek(t)`).
- `art.js` — vector art: Koutoubia, palms, red-city ramparts, zellige patterns, lanterns, plane, clouds, icons.
- `captions.js` — Arabic caption lines with per-word timings (generated by `tools/align.py` from the voice track).
- `tools/sfx.py` — synthesised sound effects mixed under the voice → `assets/mix.wav`.
- `render.js` — renders frames in headless Chromium (4 workers) and encodes with ffmpeg.

## Edit and re-render
1. Change caption text or timing in `tools/align.py` (`SCRIPT`), then run it to rebuild `captions.js`.
2. `npm install` (installs GSAP).
3. `node tools/stills.js 5 12.5 40` to preview single frames in `out/stills/`.
4. `node render.js --out out/EFH_Marrakech_CabinCrew_9x16.mp4` for the full video.
