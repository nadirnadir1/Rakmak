# EFH — Instagram reel (motion graphics)

60-second vertical reel for **EFH · École FLY HYANI Privé** (Marrakech), built around the
client's Moroccan-Darija voiceover. Everything — animation, captions, music and sound
effects — is generated by code in this folder.

## Deliverables (`output/`)

| File | What it is |
| --- | --- |
| `EFH_reel.mp4` | Final reel, 1080×1920, 30 fps, H.264 + AAC 320k, −14 LUFS (Instagram loudness) |
| `EFH_reel_sans_musique.mp4` | Same video with voice + sound effects only — add a trending Instagram sound in the app |
| `EFH_reel_cover.jpg` | Cover / thumbnail (text kept inside the 3:4 profile-grid crop) |
| `EFH_reel_captions_ar.srt` | The Arabic captions as subtitles (TikTok, YouTube Shorts, Facebook…) |

Instagram safe zones are respected: no text in the top bar area or in the bottom
caption/username area, and captions stay clear of the like/comment/share column.

## How it is made

* `tools/transcribe.py`, `tools/score_candidates.py` — Whisper large-v3 (sherpa-onnx ONNX
  export) transcription; ambiguous Darija words were decided by forced-decoding scores.
* `tools/align_words2.py` — word timings: for each word boundary the audio after a candidate
  cut is replaced by silence and Whisper picks the cut where exactly those words were said.
* `tools/build_data.py` — caption chunks / keyword boxes → `src/data.js`.
* `src/` — the composition (HTML/CSS/SVG/canvas). Every frame is a pure function of time.
* `tools/render.mjs` — renders frames with headless Chromium (Playwright), 4 workers.
* `audio/` — original music (`music.py`, 116.79 BPM, grid locked to the voiceover pauses),
  synthesized sound effects (`sfx.py`) and the mix (`mix.py`: voice on top, music ducked
  under the voice, −14 LUFS, −1 dBTP).
* `tools/encode.sh` — final H.264 encode (BT.709).

### Rebuild

```bash
cd reel
npm install                                   # d3-geo, topojson-client, world-atlas
python3 tools/prep_images.py assets/src assets/img
./tools/extract_clips.sh assets/src/clips build/frames
node tools/build_map.mjs
python3 tools/build_data.py .
node tools/render.mjs --out build/out --workers 4
python3 audio/mix.py "$PWD" build/audio/soundtrack.wav            # add `nomusic` for the voice+sfx version
./tools/encode.sh build/out build/audio/soundtrack.wav output/EFH_reel.mp4
```

Python deps: `numpy scipy soundfile pyloudnorm librosa tiktoken onnxruntime sherpa-onnx opencv-python-headless pillow matplotlib`.
