# EFH Video Studio - Remotion project

Motion-graphics promo for **École Fly Hyani Privé (EFH)**, Marrakech, with Arabic (Darija) captions synced to the voice-over in `public/voice.mp3`.

- `npm install`
- `npm run studio` to preview and edit
- `npm run render` to write `out/efh-promo.mp4` (1080×1920, 30 fps, 49 s)

Editable values are in `src/theme.ts`: phone numbers, website, brand colours and `GRAD_STAT` (the graduate percentage from the voice-over).
Caption text and timings are in `src/captions.ts`.
